# Dalal Collective

Bespoke Gemology & Fine Jewelry by Dalal Ahmed

## About
Dalal Collective offers bespoke gemstone sourcing, custom jewelry design, and expert gem consultations. Experience timeless elegance through ethical craftsmanship and precision-cut beauty.

## Features
- Bespoke gemstone sourcing
- Custom jewelry design
- Expert gem consultations
- Responsive website design
- Contact form for inquiries

## File Structure
- `index.html` - Main landing page
- `css/` - Stylesheets (main_new.css, plugins.css, loaders)
- `js/` - JavaScript files (app.js, libs.min.js)
- `img/` - Images and favicons
- `fonts/` - Custom fonts
- `video/` - Video assets
- `dalal_image/` - Dalal-specific images
- `mail.php` - Contact form handler

## Contact
For inquiries about bespoke services, please use the contact form on the website.
